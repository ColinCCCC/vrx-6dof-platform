## 1. 通信概览

| 项 | 值 |
| --- | --- |
| 控制器 | ACB750 系列运动控制板卡（软件里选择硬件版本 `ACB750`） |
| 物理层 | 以太网 UDP |
| 控制板默认 IP | `192.168.1.88`（上位机需改到同网段，通常 `192.168.1.100`） |
| 实际端口 | **`8080`**（CS_FI「通讯参数」：本地/远程端口均为 8080；手册示例 8887 为另一套配置） |
| 协议 | 可选 `FBFD32`（32 字节，平台本体/直接位姿）与 `WashOut64`（64 字节，洗出）；**当前板卡使用 FBFD32** |
| 控制模式 | UDP 正弦波摇摆台模式 / UDP 单步模式 / 路谱模式（软件「3.通讯参数」） |
| 报文长度 | 64 字节，小端（float32 / uint32 / uint8） |

## 2. 平台运动定义（手册 1.4）

平移参考坐标系 `O1XYZ`：

- **X**：侧移 Sway，**X 正 = 右移**
- **Y**：纵移 Surge，**Y 正 = 前移**
- **Z**：升降 Heave，**Z 正 = 上升**

姿态参考坐标系 `O2UVW`（右手定则；U≈X、V≈Y、W≈Z）：

- **俯仰 Pitch α**：绕 U(X) 轴，**正 = 后仰**
- **侧倾 Roll β**：绕 V(Y) 轴，**正 = 右倾**
- **偏航 Yaw γ**：绕 W(Z) 轴，**正 = 左转**
- 独立偏航 `Yaw360`（γ2）：`-180°~+180°`，正 = 逆时针（若平台带第七轴）

单位：平移 `mm`，角度 `deg`，加速度 `m/s²`，角速度 `deg/s`。

## 3. 64 字节报文结构

| 字节 | 字段 | 单位 | 类型 | 说明 |
| --- | --- | --- | --- | --- |
| 0–3 | 时间戳 | ms | uint32 | 小端，板卡 uptime 或主机时间均可 |
| 4–7 | x 方向位移 | mm | float | Sway |
| 8–11 | y 方向位移 | mm | float | Surge |
| 12–15 | z 方向位移 | mm | float | Heave |
| 16–19 | 绕 x 轴旋转角度 | deg | float | Pitch（正 = 后仰） |
| 20–23 | 绕 y 轴旋转角度 | deg | float | Roll（正 = 右倾） |
| 24–27 | 绕 z 轴旋转角度 | deg | float | Yaw（正 = 左转） |
| 28–31 | x 方向加速度 | m/s² | float | 洗出模式用 |
| 32–35 | y 方向加速度 | m/s² | float | 洗出模式用 |
| 36–39 | z 方向加速度 | m/s² | float | 洗出模式用 |
| 40–43 | 绕 x 轴旋转角速度 | deg/s | float | 洗出模式用 |
| 44–47 | 绕 y 轴旋转角速度 | deg/s | float | 洗出模式用 |
| 48–51 | 绕 z 轴旋转角速度 | deg/s | float | 洗出模式用 |
| 52–55 | 预留 1 | — | — | 第七轴旋转角或保留（实测示例在此填第七轴角度） |
| 56 | 平台控制指令 | — | uint8 | 见第 5 节 |
| 57 | Length | — | uint8 | 填 1–17 的数值（示例为 1） |
| 58 | Velocity | — | uint8 | 默认 50，范围 0–100；100 对应电机 3000 转 |
| 59 | Accelerate | — | uint8 | 默认 10，范围 0–100；加速到额定转速所需时间，单位 10 ms |
| 60–62 | 固定字节 | — | uint8 | `0x54 0x6F 0x43`（`'T','o','C'`） |
| 63 | 参数校验 | — | uint8 | `Σ(Byte0…Byte62) & 0xFF` |

### 3.1 两种使用模式（协议表右侧两列）

- **平台本体（直接位姿）**：使用 `Byte0–3` 时间戳 + `Byte4–27` 位移/角度。
  → 平台直接复现给定位姿，**本项目采用此模式**。
- **模拟驾驶（洗出算法）**：使用时间戳 + `Byte16–23` 角度 + `Byte28–39` 加速度 + `Byte48–51` 偏航角速度。
  → 驾驶模拟器运动洗出（会滤除持续加速度），不适合复现甲板运动。

## 4. 坐标映射（Gazebo → 平台）

Gazebo/ROS 采用 REP-103：`marine_am_boat` 机体坐标系为 **X 前 / Y 左 / Z 上**。
平台坐标系为 **X 右 / Y 前 / Z 上**。

轴变换矩阵（机体 → 平台）：

```text
A = [[ 0, -1, 0],
     [ 1,  0, 0],
     [ 0,  0, 1]]
```

- 位置：`p_platform = A · R_refᵀ · (p_cur − p_ref)`
- 姿态：`R_platform = A · (R_refᵀ · R_cur) · Aᵀ`
- 从 `R_platform` 按 `R = Rz(yaw)·Ry(roll)·Rx(pitch)` 提取：
  - `pitch = atan2(R[2][1], R[2][2])`
  - `roll  = asin(−R[2][0])`
  - `yaw   = atan2(R[1][0], R[0][0])`

其中 `p_ref`、`R_ref` 为参考位姿（可取启动瞬间位姿或低通均值）。

## 5. 平台控制指令（Byte56 位定义，已与用户确认）

| bit | 功能 | 取值 |
| --- | --- | --- |
| 5 | 是否采用洗出算法 | `0` 不采用 / `1` 采用 |
| 4 | 开关机指令 | `0` 无操作 / `1` 主站关机 |
| 1–0 | 启停控制指令（连续发送） | `0` 待机（平台处于中位）/ `1` 工作（运行状态）/ `2` 停止（平台归到最低位）/ `3` 暂停（平台保持当前位置） |
| 其余 | 保留 | 填 0 |

本项目的正常输出：`bit5=0`（平台本体模式）、`bit4=0`、`bits1–0=1`（工作）→ **`0x01`**。
失联/停止时发送 `bits1–0=3`（暂停，保持当前位置）或 `0`（待机），见节点参数。

## 6. 校验与示例

校验：`Byte(63) = (Byte(0) + Byte(1) + … + Byte(62)) & 0xFF`。

手册示例（**模拟驾驶/洗出模式**，故位移写在加速度槽）：

- 俯仰 100° → `Byte16` = 100.0；侧倾 100° → `Byte20`；偏航 100° → `Byte48`（偏航角速度）
- 侧移/纵移/升降 100 → `Byte28/32/36`（加速度）
- 尾部恒为 `01 01 32 07 54 6F 43 xx`（Length=1、Velocity=50、Accelerate=7、固定字节、校验）

以「侧移 100mm」示例验证：`Byte0…62` 逐字节求和 = `0x38B`，低 8 位 `0x8B` 与报文末字节一致。

## 7. 实现备注（本项目）

- ROS 2 节点：`marine_am_platform/deck_pose_bridge`（Python）。
- 数据源：Gazebo 中单体船的模型位姿 TF（`vrx_smoke_test` → `marine_am_boat`）。
  该 TF 由项目自己的 `marine_am_gz_bridge`（C++ 节点）从 Gazebo transport 的
  `/world/<world>/pose/info` 中提取 `marine_am_boat` 模型位姿后广播，VRX 子模块保持上游原样。
- 默认 `dry_run=true`，只打印/记录报文不实际发送；上线前先确认平台 IP、端口与模式。
- 安全：位移/角度限幅、无位姿超时发送「暂停」、可在线使能/停用。
- 上下行：下行使用 64 字节报文（网口 `192.168.1.100:8080` → 平台 `192.168.1.88:8080`）；
  平台默认开启「自动回传」，周期性发送 180 字节上行帧（实测约 20 Hz，平台运动时更快）。
  上行帧结构（实测推断，字段表缺失）：

  | 偏移 | 内容 |
  | --- | --- |
  | 0–2 | 帧头 `eb 90 11` |
  | 32–55 | 6 个 float32，疑为六路电机转速（运动中约 75，静止为 0） |
  | 88–115 | 7 个 float32，疑为温度/电流等状态量 |
  | 144 | `0x0aaa` 固定标记 |
  | 152 | `0x04` 疑似报文类型 |
  | 172–175 | uint32 递增计数器 |
  | 176–179 | 帧尾 `b0 b1 b2 b3` |

  该回传为周期上报，不需要发送命令也会持续（实测无命令时仍有数据）。


## 8. FBFD32 协议（平台本体，当前使用）

32 字节，帧头 `FB FD`，直接下发六自由度位姿：

| 字节 | 字段 | 类型/单位 |
| --- | --- | --- |
| 0–1 | 帧头 `0xFB 0xFD` | — |
| 2–5 | 侧移 X | float, mm |
| 6–9 | 纵移 Y | float, mm |
| 10–13 | 升降 Z | float, mm |
| 14–17 | 俯仰角 | float, deg |
| 18–21 | 侧倾角 | float, deg |
| 22–25 | 偏航角 | float, deg |
| 26 | 幅度 | uint8，默认 100，范围 0–100 |
| 27 | 速度 | uint8，默认 50，范围 0–100（100 对应电机 3000 转） |
| 28 | 柔度 | uint8，默认 10，范围 0–100（加速到额定转速时间，单位 10 ms） |
| 29–30 | 保留 | — |
| 31 | 校验 | `Σ(Byte1…Byte30) & 0xFF` |

实测（板卡切到 FBFD32 后）：x/y/z 平移、俯仰/侧倾/偏航全部生效，六路执行器长度按几何关系正确变化。
项目节点默认 `protocol:=fbfd32`；`WashOut64` 保留为可选（洗出/模拟驾驶模式）。
