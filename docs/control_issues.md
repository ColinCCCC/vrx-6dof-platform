# 波浪补偿控制：问题与改进方向

## 当前控制链路

世界系目标 → 位姿误差 → ESO/ADRC（扰动估计）→ 基座速度/加速度前馈
→ FX-LMS（周期分量）→ `J⁺` → 关节速度环 → Gazebo / 实机。

## 已知问题

| 问题 | 现象 | 根因判断 |
| --- | --- | --- |
| ESO 超调 | 波峰后出现明显过冲 | 观测器带宽与位置环增益叠加；`d_hat` 突变 |
| 峰值误差 | 最大 20 mm 左右，均值 5–10 mm | 目标接近工作空间边界 + 相位滞后 |
| FX-LMS 收敛慢 | 间歇浪第一个波峰必然打上 | 学习型控制需要 1–3 个周期 |
| 频率漂移 | 估计值约 2.1 s（设定 2.0 s） | 过零检测 + 低通，存在偏差 |
| 启动瞬态 | 锁定后前几秒误差大 | 目标/观测器/机械臂同时进入稳态 |
| 船体漂移 | 固定世界目标会逐渐超出臂展 | 缺少平台定位保持 |

## 已做缓解

- `d_hat` 限幅、50 ms 低通、补偿输出限幅；
- 锁定后 3 s 软启动；
- FX-LMS 使用实测升沉/速度作参考 + NLMS 归一化；
- 降增益（`eso_wo=6`、`kp_pos=8`）。

## 可改进方向

1. ESO 只估计低频扰动，波峰交给前馈；
2. 目标轨迹平滑/限速，避免阶跃修正；
3. 增益调度：启动低增益，稳定后切换；
4. 加入平台定位保持（或慢漂移跟随）避免目标越界；
5. 用实测频响设计相位超前，而不是盲调增益；
6. 实机验证前先做关节限位/速度限制的硬件在环。

## 测试协议

- 每个 trial 前重新锁定目标；
- 窗口 10–15 s，避免漂移污染；
- 同时记录船体升沉、末端误差和关节指令。
